# `/interviews`

Source: `src/app/(app)/interviews/page.tsx:8`

Applicant-only list of active fair/direct invitations. Fair invitations show role/fair/location/date and allow a confirmed 15-minute slot booking; direct invitations show a 14-day response window, privacy explanation, and accept/decline controls. Empty state links to `/dashboard`.

Back: only the empty-state CTA; no general contextual back link when invitations exist.
