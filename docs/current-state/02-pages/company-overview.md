# `/company`

Source: `src/app/(app)/company/page.tsx:4`

Approved-company member overview. Shows active role, current match, and slot counts, a candidates CTA, and the privacy model for anonymized candidates/consented profiles. Owners can maintain the public company profile (name, website, sector, operating location, public phone, and description); recruiters see the same workspace with the profile kept owner-controlled. A successful recruiter invitation acceptance can show a joined-workspace status message. Uses company management navigation.
