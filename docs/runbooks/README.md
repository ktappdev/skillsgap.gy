# Runbooks

Short operational procedures for SkillsGap.gy. Each one is limited to what the repository and `AGENTS.md` record. Where the repo does not say how to do a step, the runbook says to confirm before use.

- [Deploy](deploy.md): deploying the Vercel app, Auth allow-list for preview URLs, DNS, and database deployment.
- [Rotate secrets](rotate-secrets.md): where each secret lives and how to rotate it.
- [Demo reset](demo-reset.md): preparing the demo fallback, and the `reset:db` modes and warnings.
- [Rollback](rollback.md): promoting a previous deployment, and shipping a corrective migration.
